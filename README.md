# Adiyogi Travels Solapur — Website

A responsive, single-page HTML/CSS/JavaScript travel website.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. For best results, run a local static server (for example VS Code Live Server).

## Included
- Responsive navigation and mobile menu
- Hero section, pilgrimage destinations, vehicle fleet, packages and about section
- Trip enquiry form with client-side validation
- WhatsApp enquiry message prefilled with form details
- Direct call links and floating WhatsApp button

## Contact configuration

To change phone numbers, update the `tel:` links and visible numbers in `index.html`.

## Images
Images are loaded from Unsplash over the internet. Replace image URLs in `index.html` and the hero/quote background URLs in `styles.css` with approved business photos before production launch.

## Important before publishing
- Confirm the exact vehicle photos and destination photographs.
- Confirm package prices, inclusions, pickup areas, operating hours and booking terms.
- Add a privacy policy if collecting or storing enquiries in a backend. This version sends the entered details directly to WhatsApp and does not store them.
